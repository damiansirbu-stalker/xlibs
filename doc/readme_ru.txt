xlibs: Разделяемая библиотека утилит для моддинга STALKER Anomaly, автор Damian
Версия: 1.8.4
GitHub: https://github.com/damiansirbu-stalker/xlibs
Changelog: https://github.com/damiansirbu-stalker/xlibs/blob/main/doc/changelog
English: https://github.com/damiansirbu-stalker/xlibs/blob/main/doc/readme.txt
Bugs, suggestions: https://github.com/damiansirbu-stalker/xlibs/issues

xlibs — набор инструментов моддера, покрывающий весь спектр того, что обычно нужно модам Anomaly: запросы к сущностям, операции с отрядами, логика смарт-террейнов, работа с тайниками, логирование, профилирование, системы событий и структуры данных.

Дизайн API вырос из обратной разработки движка X-Ray и внутренностей Anomaly, сверенной с приёмами лучших моддеров европейской и русской традиций моддинга STALKER. Каждая функция оборачивает причуды движка, защищает от nil и обрабатывает крайние случаи, которые иначе каждому моду пришлось бы решать самостоятельно.

Чистый Lua там, где это возможно. Никакой зависимости от движка без необходимости. Никакого центрального загрузчика: движок сам подгружает скрипты при первом обращении. Просто вызовите xlog.get_logger() или xsquad.find_squads(), и всё работает.

Возможности:

Сущности и мир:
  xactor       Инфопорции актора, партнёр по диалогу и торговле, запросы состояния
  xcreature    Определение существ, проверки типов, переведённые имена, примитивы для денег
  xsquad       Поиск отрядов, скриптовый контроль, освобождение, преследование, перебор
  xsmart       Запросы к смарт-террейнам, определение фракции, вместимость, прибытие, захват, распределение работ
  xlevel       Запросы к уровню/карте, игровое время, названия локаций, проверка вершин
  xobject      Разрешение серверного объекта и онлайн игрового объекта из любого типа входных данных
  xinventory   Категоризация предметов (тир патронов по NPC), семантика слотов, конфиг патронов, жизненный цикл предметов, примитивы политики LTX (загрузка + классификация + перебор излишков)
  xstash       Обнаружение тайников, обыск, наполнение, фильтрация предметов
  xdata        Таблицы нескриптуемых NPC/отрядов (торговцы, механики, сюжетные персонажи)
  xconst       Служебные константы движка X-Ray (недопустимый ID сущности, недопустимый ID вершины уровня)

Структуры данных:
  xtable       Подсчёт, перемешивание, сортировка, объединение и вычитание множеств
  xttltable    Хранилище ключ-значение с TTL, счётчик скользящего окна, token bucket, FIFO-кэш
  xmath        Случайная выборка и частичное перемешивание
  xslice       Перебор массива, нарезанный по кадрам
  xstring      Интерполяция строк с плейсхолдерами {key}
  xtime        Накопитель игровых секунд (оборачивает game_time() движка)

Диагностика:
  xlog         Буферизованное файловое логирование с управлением сессиями и ротацией
  xprofiler    Микросекундное профилирование кода через profile_timer движка
  xtrace       Генерация trace ID для отслеживания запросов между модулями
  xinspect     Глубокий разбор таблиц и userdata, определение типов движка

Эффекты:
  xpp          Обёртка пост-процесс эффекторов (аллокатор слотов, сглаженный движком фактор, handle API; 35 проверенно безопасных путей .ppe)
  xsound       Обёртка зацикленного звука (handle API, плавное изменение громкости на стороне Lua, ленивый тик actor_on_update)

Интеграция:
  xbus         Шина событий pub/sub (прямая доставка, ошибки остаются видимыми)
  xevent       Перехват функций в рантайме для синтетических колбэков
  xpda         Сообщения ПДА и метки на карте (отряд и сущность)
  xmcm         Набор конфигурации MCM (предзаполненная таблица, геттер, загрузчик)
  xchange      Реестр миграций сохранений в стиле Liquibase; каждый changeset выполняется один раз на сохранение

Требования:
Anomaly 1.5.3

Установка (MO2):
1. Установите xlibs
2. Порядок загрузки не важен (движок подгружает скрипты по требованию)

Удаление (MO2):
Отключите или удалите в MO2. Любой мод, зависящий от xlibs, перестанет работать.

Настройка:
Настройка не требуется. xlibs — пассивная библиотека, подгружаемая по требованию другими модами.

Совместимость:
Работает на модифицированных exe themrdemonized 2025.9.10 или новее, либо AOEngine v0.55 или новее.
Чистая библиотека. Не изменяет базовые скрипты и не добавляет собственного игрового поведения. xlog регистрирует колбэки сброса буфера на сохранение и смену уровня, а также таймер периодического сброса при старте игры; всё остальное остаётся в покое, пока мод не вызовет это. Совместима со всем, включая GAMMA.

Разработка:
Написана по исходникам движка X-Ray Monolith, исходному коду exe Demonized и распакованной gamedata Anomaly 1.5.3.
Приёмы кода и использование движка выверены по признанным работам уважаемых моддеров GAMMA (Demonized, Vintar0, RavenAscendant, xcvb).
Код проверяется в реальном времени многоступенчатым конвейером: luacheck, selene, анализ AST через tree-sitter, контрактные правила, разрешение межфайловых зависимостей, анализ цикломатической сложности, обнаружение паттернов крашей и уязвимостей, интеграционные тесты на lua54 с заглушками движка X-Ray, поиск секретов gitleaks.
Полный отчёт в doc/test-report.log.

FAQ:
Нужны ли модифицированные exe?
  Да. xlibs нужны модифицированные exe themrdemonized (2025.9.10 или новее) или AOEngine (v0.55 или новее). Ванильная Anomaly не предоставляет API, на которые она опирается.
